# R1 - Edit Department on the project card

## User story
As a project user, I want to edit the Department on the project card, so that the dimension stays up to date.

## Acceptance criteria
The Department dimension is the dimension in `Global Dimension 1 Code` of General Ledger Setup.
1. Given a project without a department, when the user sets Department to `SALES` on the project card, then a
   default dimension for the project exists with that dimension and dimension value `SALES`.
2. Given a project with department `SALES`, when the user changes Department to `ADM`, then the project has
   exactly one Department default dimension and its value is `ADM`.
3. Given a project with department `SALES`, when the user clears Department, then the project has no
   Department default dimension.
4. Given a project whose default dimension Department is `SALES`, when the project card is opened, then the
   Department field shows `SALES`.

## Interface
- Object: `pageextension 50100 "Job Card Department"` extends `"Job Card"` in `src/R1/JobCardDepartment.PageExt.al`
- Field: `Department` (`Code[20]`, bound to a variable) on the card. The stub has no behaviour: nothing is read
  from or written to the dimension.

## Expected red-phase failure
The tests compile (the field exists) and fail on assertions: the dimension is never written or read.
