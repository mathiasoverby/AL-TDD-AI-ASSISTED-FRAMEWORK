# R2 - Brand, Model and Variant lookups on the vehicle

## User story
As a fleet manager, I want to choose Brand, then Model, then Variant from lookup tables, so that a brand is not
spelled in different ways.

## Acceptance criteria
1. Given brand `B1`, model `M1` of `B1` and variant `V1` of `B1`/`M1`, when Brand, Model and Variant are validated
   on a vehicle in that order, then all three are stored without error.
2. Given a vehicle with brand, model and variant, when Brand is changed, then Model and Variant are cleared;
   when only Model is changed, then Variant is cleared.
3. Given model `M2` that belongs to brand `B2`, when it is validated on a vehicle with brand `B1`, then the error
   `Model M2 does not belong to brand B1.` is raised.
4. Given variant `V2` that belongs to another model, when it is validated on a vehicle, then the error
   `Variant V2 does not belong to model M1.` is raised.
5. Given brand `Volkswagen`, when a brand with the same name in other casing (`VOLKSWAGEN`) but another code is
   inserted, then the error `Brand VOLKSWAGEN already exists.` is raised.
