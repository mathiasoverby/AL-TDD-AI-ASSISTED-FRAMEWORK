# R3 - Colour-coded initials by qualification status

## User story
As a project user, I want the initials colour-coded by qualification status, so that invalid choices are visible.

## Acceptance criteria
The style is derived from the standard `Employee Qualification` records (`Qualification Code`, `From Date`,
`To Date`; an empty `To Date` is open-ended). A record is valid on a date when `From Date <= date` and
(`To Date` is empty or `date <= To Date`).
1. Given a valid qualification record on the date, then the style is `Standard`.
2. Given the date equals `From Date`, or equals `To Date`, then the style is `Standard`.
3. Given the date is the day after `To Date` (or the day before `From Date`), then the style is `Attention`.
4. Given the employee has no record for the qualification code, then the style is `Unfavorable`.
5. Given several records for the same code, when one of them is valid on the date, then the style is `Standard`;
   when the date lies between two periods, then the style is `Attention`.
