# R5 - Date of last ownership status change

## User story
As an accountant, I want the date of the last ownership status change set automatically, so that changes are
traceable.

## Acceptance criteria
The fields live on the fixed asset. "Today" is the system date (`Today`).
1. Given a fixed asset, when `Ownership Status Code` is set to a status, then `Ownership Status Date` is today.
2. Given a fixed asset with status `OWNED` and a date in the past, when the status is changed to `LEASED`, then
   the date is today.
3. Given a status that was just set (date is today), when the user sets `Ownership Status Date` to a past date,
   then that date is kept (manual override).
4. Given a fixed asset with a status and a date, when the user clears `Ownership Status Date`, then it stays
   empty and the status is unchanged.

## Interface
- `table 50170 "Ownership Status"` (`Code` Code[10] key, `Description` Text[50]) in `src/R5/OwnershipStatus.Table.al`
- `table 50171 "Ownership Type"` (`Code` Code[10] key, `Description` Text[50]) in `src/R5/OwnershipType.Table.al`

  `Ownership Status Code` (Code[10], relation to `"Ownership Status"`), `Ownership Type Code` (Code[10], relation
  to `"Ownership Type"`) and `Ownership Status Date` (Date). No validation logic in the stub.
